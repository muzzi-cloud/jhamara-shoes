# Jhamara Shoes — Ultimate Storefront Demo

## Project
A responsive storefront mixing a premium modern sneaker-shop feel with Pakistani footwear heritage: women's khussas and mojari, men's Peshawari and Chitrali-style chappals, sandals, plus modern sneakers.

## Included
- 16 sample products with individual image URLs and product names
- Responsive hero, collections, craft/story sections and newsletter form
- Category filters, live search and price sorting
- Shopping bag, quantity controls, remove item, subtotal and checkout demo message
- Wishlist toggles, mobile navigation, toast messages
- Accessible image alt text, lazy-loaded product images, reduced-motion support

## Run
Open `index.html` in a browser. No build step required.

## Important before production
This is a front-end demo, not a live ecommerce system. It does not process orders, payments, inventory, customer accounts, or shipping. Product photos load from Unsplash and require internet access; remote photos may not match the exact traditional footwear named. Replace them with product photography you own or are licensed to use, then add actual sizes, stock, delivery/return policies, contact information and a secure backend/payment provider. Prices are illustrative PKR examples.
